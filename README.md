# MNIST Handwritten Digit Classification

A deep learning project for classifying handwritten digits from the **MNIST dataset** using **Keras / TensorFlow**.

## Project Overview

This project builds and trains a neural network to recognize handwritten digits from **0 to 9**. The notebook covers data preparation, exploration, preprocessing, model building, training, and evaluation.

## Dataset

The project uses the MNIST handwritten digit dataset available through Keras. It contains grayscale images with a resolution of **28 × 28 pixels**.

- Training images: 60,000
- Test images: 10,000
- Classes: 10 digits (0–9)

## Workflow

- Load the MNIST dataset
- Explore image and label dimensions
- Prepare and preprocess the data
- Build a neural network using Keras
- Train the model on the training dataset
- Evaluate classification performance on unseen test data
